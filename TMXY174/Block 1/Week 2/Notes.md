 # SD: 12:07 TMXY174 - Unit 2: Project lifecycle

 **Project lifecycle** is a structured sequences of phrases that it is used to organise and manage a project from it's beginning through completion

 The general steps int terms of cycle completion
 ->
* 1 - Initiation
* 2 - Planning
* 3 - Execution
* 4 - Monitoring and Execution
* 5 - Closure



## Phase 1: Initiaton

Defining or what the project is going to be from a high level

-> Main goals for **Initiaion** phase is 
    - why the project should exist
    - what success will look like
    - whether it's feasable from a technical standpoint
    - Important weighing is Time & Money since that's a key factor

**Project Charter** A document developing during project initation that formally establish the project and supports a approval to proceed.
